About the project:

This project is a TCP Server Website written in C, using only the necessary Linux socket libraries on Arch Linux. To connect the frontend with the TCP server, I implemented a Gateway Server. It receives JSON data from the frontend and forwards it to the TCP server, where operations such as encryption can be performed. The project also uses Docker to make it possible for Windows users to run the application. Although a TCP server is not strictly necessary for a website with a C backend, my goal was to demonstrate how TCP communication can be integrated into a web application. The planned visualizer will display the TCP packets exchanged between the gateway and the TCP server, making the communication process easier to understand. Currently, the TCP server sends data to the gateway over TCP. The gateway then converts the received data into JSON and forwards it to the frontend for rendering. The TCP visualizer is still under development. However, the underlying communication already works: the server currently prints the hexadecimal data to the terminal, while the website successfully displays standard HTML content. This demonstrates that both the TCP communication and the frontend rendering are already functional.
