About the project:

The project renders one Dashboard for each project (I have two data projects). For this, I used Dash, so I didn't have to create a backend, but I am not sure if creating one would be that much harder for me now. The data ETL process is done beforehand, and I have divided the next steps into Machine Learning (ML) and Data Analysis. I didn't include the ML graphs in the Dashboard because I don't think they belong there, but they could have been included. I created two reports, which cover most of what the ML process is about, including images. For these reports, I used Markdown (MD) files and Quarto to generate automated PDF reports. The graphs in the Dashboard are Plotly graphs, but in my Jupyter Notebooks (ipynb) and reports, I also used Matplotlib.

Tools:

Python, Pandas, Scikit-Learn, numpy, matplotlib, plotly, dash, Quarto (for automated reports)
