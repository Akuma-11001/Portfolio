About the project:

The project is a Full-Stack Dashboard that uses FastAPI for the backend and React for the frontend. It features a Login and Registration System, with user data stored in a PostgreSQL Database. Each user is assigned a role (Admin or User). Based on their role, users receive different access permissions and are redirected to different dashboard URLs. Currently, both dashboards share the same functionality, but the login system already handles role-based redirection. The dashboard currently renders Plotly graphs generated by the Python backend and includes a User Management Table with filtering and search capabilities. The project also uses Docker for containerization. The application is still under active development, with additional features and improvements planned.
